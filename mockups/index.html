抖音 Web UI 重写 · 三个风格方向

每个页面都是独立 HTML，自带可点的模拟播放器：点击进度条可以体验「进度条跟手 → 跳转中… → 约 1.6 秒后画面到位」的交互（这正是真实抖音上要修的那个问题）。

方案 A

Semi Clean

Semi Design 语言：白底、8px 圆角、蓝色主色、紧凑密度。信息分栏清晰，最接近「官方工整版」，改造成本最低。
方案 B

Cinema

影院沉浸式：纯黑背景、视频最大化、导航默认隐去、信息叠在画面上、评论收进底部抽屉。最「刷视频」。
方案 C

Editorial

杂志式：米白纸感、衬线大标题、结构化元信息网格、侧栏卡片（作者/编者按/推荐）。信息密度最高，最「可读」。

说明：这三页是视觉方向样稿，不含真实数据、不联网、可直接双击打开。
也可以混搭，例如：A 的排版 + B 的深色 + C 的标题字号。挑好方向后我们再谈：顶部导航精简到哪几项、右侧栏保留什么、评论如何折叠、播放器控制条范围，以及是否做深色模式。
